# chat-app

## 项目简介

这是一个面向小团队或私有部署场景的轻量聊天应用仓库，包含 Web 端、后端和桌面端打包能力。

## 当前定位

- 轻量聊天应用
- 小团队内部通信工具
- Web + 桌面端双形态项目
- 可继续扩展为私有化部署聊天系统

## 当前结构

- `backend/`：后端服务
- `frontend/`：网页前端
- `electron/`：桌面端外壳
- `dev.sh`：开发模式启动脚本
- `start.sh`：生产模式启动脚本

## 当前能力

- 用户注册与登录
- 联系人搜索与添加
- 单聊实时消息
- Web 部署
- Windows EXE 打包
